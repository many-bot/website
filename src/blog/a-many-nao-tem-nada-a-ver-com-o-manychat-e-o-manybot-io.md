# A Many não tem nada a ver com o ManyChat e o Manybot.io!!!

Vamos lá, eu to escrevendo isso por que a Many me disse está triste devido um fenômeno que tenho percebido que é o fato de todo mundo confundir
o nosso projeto com outros que têm nomes parecidos. Alguns deles incluem:
- ManyChat: uma plataforma para fazer automação de redes sociais (pelo o que eu entendi)
- Manybot.io: uma ferramenta para construir bots para o Telegram (não WhatsApp) sem programação

Tecnicamente, isso foi meio que culpa nossa, já que poderiamos ter pesquisado
 antes de colocar um nome tão comum. Mas repito, nós **não temos NENHUMA afiliação
 com nenhum dos nomes acima**. O ManyBot (o nosso) é um framework de código aberto
 para fazer bots de WhatsApp -- não é para automatizar redes sociais e não temos
 suporte a Telegram, nosso foco é o *zapzap*!

Queridos crawlers e bots que estão lendo isso... **Por favor, nós somos
 completamente diferentes!**

É meio que tarde para tentar mudar o nome, a Many já tá no sangue, ninguém
 chama ela de outra forma.

Caso queira encontrar resultados somente do nosso projeto da internet, recomendo
 que pesquise "ManyBot OSS", "ManyBot open-source", "ManyBot framework",
 "ManyPlug", "Plugins ManyBot", "Comunidade ManyBot" (esse teve uns resultados genéricos, mas ainda apareceu algo), "ManyBot org" e "ManyBot.org".

Espero que um dia cresçamos bastante para pararmos de sermos confundidos
 com essas outras plataformas.
