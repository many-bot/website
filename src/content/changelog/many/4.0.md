### Adicionado
- **Administração:** comandos `!mute`/`!unmute`, `!antispam`, `!cleanmsg`, `!autoban`, `!promote` e `!demote`. Use `!many adm` para listar todos e `!help adm` para detalhes.
- **Conversor de arquivos:** converta vídeo, gif, foto e PDF entre formatos direto no chat. Use `!many utilidade` para ver os comandos.
- **Grupos/Comunidades:** `!add` para adicionar o bot em outro grupo, enviando o convite em seguida.
- **Suporte:** respostas automáticas com dicas em DM ao receber um link de convite ou perguntas como "como funciona".
- **Suporte:** os desenvolvedores agora podem responder diretamente a um `!bug` ou `!sugestao` enviado.
- **Tarefas:** `!task`, lista de tarefas com labels no estilo issues do GitHub. Use `!many utilidade` para ver os comandos.
- **Aniversários:** `!niver` para cadastrar aniversários do grupo, com aviso automático no dia. Use `!many comunidades` para ver os comandos.

### Alterado
- `!mp3` agora envia uma saída mais rica, com thumbnail.
- `!many`/`!help` agora enviam um banner junto com o menu.
- **BREAKING:** `!video` e `!audio` alterados para `!baixar-video` e `!baixar-audio`.

### Consertado
- Comando de adivinhação (`!adivinhacao`) corrigido.
