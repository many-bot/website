### Adicionado
- `validate` agora faz um type-check de verdade no arquivo principal do plugin usando `@manybot/types` -- pega erros que o scan por regex passava batido (aliases, desestruturação, handles de mensagem enviada).
- `validate` atualiza o `@manybot/types` sozinho antes de rodar, para sempre checar contra a API mais recente.
- `validate` avisa quando existe uma versão mais nova do ManyBot disponível.
- Warnings agora mostram `arquivo:linha:coluna` e um trechinho do código apontando o problema, estilo `tsc`.
- `info` ganhou o alias `show` e agora mostra para onde um symlink (criado pelo `link` aponta.

### Alterado/Corrigido
- `validate` não duplica mais avisos de `ctx.*` quando o type-checker já cobriu aquele trecho.
- Desestruturação com apelido (`{ msg: mensagem } = ctx`) agora aponta pro nome certo no aviso.
- `ctx.msg.reply()` chamado direto agora é reportado em todas as ocorrências, não só na primeira -- dado em vista que é um erro bem comum.
- `info` sempre mostra o caminho absoluto do plugin.

### Removido
- Mensagens antigas de versão do ManyBot no `validate`, substituídas pelas novas de versão instalada / atualização disponível. Mais claras de entender.
