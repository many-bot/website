O que é o ManyBot?
O ManyBot é um framework que facilita a criação de bots para o WhatsApp, assim como no Discord.

O projeto é de código aberto (GPLv3) e é mantido pela comunidade. Contribuições são bem-vindas — de código a sugestões de API. Se quiser, também dá pra apoiar com doações de qualquer valor.

Objetivo
Nosso objetivo é desenvolver um sistema aberto para facilitar o desenvolvimento de bots, e tornar essa prática mais popular e aberta.
