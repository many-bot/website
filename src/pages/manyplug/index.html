ManyPlug

O gerenciador de plugins oficial do ManyBot. Instala, ativa, atualiza e valida plugins direto do terminal — sem mexer em código do core.

npm: @manybot/manyplug requer Node.js 24+ roda como manyplug ou mp 
npm install -g @manybot/manyplug

Comandos principais

A referência completa (todos os comandos e opções) está na documentação.

manyplug init
Cria o esqueleto de um plugin, pluginpack ou profile.
→
manyplug install
Instala plugins, pluginpacks ou profiles do registry ou local.
→
manyplug link
Symlink de um plugin local — edições valem na hora.
→
manyplug search
Busca plugins no registry por nome, categoria ou descrição.
→
manyplug validate
Checa o manifesto, dependências, locale/ e uso do ctx antes de publicar.
→
manyplug update
Reinstala todos os plugins não-locais com as versões mais recentes.
→
