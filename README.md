# Manybot Website

This project is built using [Astro](https://astro.build/) and [@astrojs/starlight](https://starlight.astro.build/).

## Getting Started

### Prerequisites

- Node.js >= 22.12.0

### Installation

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:3003`.

### Build

Build the site for production:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```
