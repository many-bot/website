# New plugin: ManyMedia

Today, a new plugin was added to the ManyPlug repository: "ManyMedia".

This plugin aims to unify the "video" and "audio" plugins into a single one, as well as fix various bugs the old ones had when downloading videos from Reddit and Instagram.

> Important: if you have any of these plugins installed and want to use ManyMedia, it's recommended to remove them first to avoid conflicts.

The plugin will receive more updates soon to ensure absolute compatibility with any link from any social network on the Internet.

The commands for using it remain the same as "video" and "audio". Example:

```
!video https://example.com/...
```

and:

```
!audio https://example.com/...
```

---

To install the plugin in your ManyBot project, use the following command:

```
manyplug install manymedia
```

And enable it:

```
manyplug enable manymedia
```

> Check dependencies before using.
