What is ManyBot?
ManyBot is a framework for to make easy to build WhatsApp bots, like it is on Discord.

The project is open source (GPLv3) and community-maintained. Contributions are welcome — from code to API suggestions. If you'd like, you can also support with donations of any value.

Goal
Our goal is to build an open system that makes it easier to develop bots, and to make that practice more popular and open.
