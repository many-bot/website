ManyPlug

ManyBot's official plugin manager. Installs, enables, updates and validates plugins right from the terminal — no need to touch core code.

npm: @manybot/manyplug requires Node.js 24+ runs as manyplug or mp 
npm install -g @manybot/manyplug

Main commands

The full reference (all commands and options) is in the documentation.

manyplug init
Creates the skeleton for a plugin, pluginpack or profile.
→
manyplug install
Installs plugins, pluginpacks or profiles from the registry or locally.
→
manyplug link
Symlinks a local plugin — edits apply instantly.
→
manyplug search
Searches the registry for plugins by name, category or description.
→
manyplug validate
Checks the manifest, dependencies, locale/ and ctx usage before publishing.
→
manyplug update
Reinstalls all non-local plugins with their latest versions.
→
